# C Programming Code Collection

A collection of basic C programming examples and practice programs.

## Files

- [`code2.c`](code2.c): Basic print statements and greeting.
- [`recursion.c`](recursion.c): Power calculation using recursion.
- [`repetition.c`](repetition.c): Loop and repetition logic example.
- [`Repetition code.c`](Repetition%20code.c): Loop and repetition logic example.

## How to Compile & Run

Using GCC:
```bash
gcc filename.c -o filename.exe
./filename.exe
```
